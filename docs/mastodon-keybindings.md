# Mastodon 快捷键速查

本文档汇总了当前 Emacs 配置中 Mastodon 客户端（`mastodon.el`）的全部快捷键。

## 基本信息

| 项目 | 值 |
|------|------|
| 配置位置 | `lisp/git-package.el` |
| 加载方式 | `use-package` 按需加载（`M-x mastodon` 时才载入） |
| 实例地址 | `https://social.13140000.xyz` |
| 活动用户 | `wdd` |

> **启动**：配置中没有绑定全局快捷键，使用 `M-x mastodon` 进入。
> 之后所有快捷键均在 mastodon buffer 内使用。

---

## 一、时间线浏览（`mastodon-mode-map`）

### 1.1 导航

| 按键 | 功能 |
|------|------|
| `n` / `p` | 下一条 / 上一条嘟文 |
| `TAB` / `S-TAB` | 下一个 / 上一个可交互项（链接、媒体） |
| `M-n` / `M-p` | 下一个 / 上一个可交互项（同上） |
| `SPC` | 向下滚动 |
| `l` | 重新居中（recenter） |

### 1.2 切换时间线

| 按键 | 功能 |
|------|------|
| `H` | 主页时间线（Home） |
| `L` | 本站时间线（Local） |
| `F` | 联邦时间线（Federated） |
| `N` | 通知 |
| `@` | 提及我的通知 |
| `S-C-n` | 关注请求 |
| `s` | 搜索 |
| `#` | 查看 `#标签` 时间线 |
| `C-#` | 已关注标签列表 |
| `'` | 已关注标签时间线 |
| `C-'` | 标签分组时间线 |
| `/` | 切换 mastodon buffer |
| `\` | 远程实例的本地时间线 |

### 1.3 Buffer / 窗口控制

| 按键 | 功能 |
|------|------|
| `g` / `u` | 刷新当前时间线 |
| `q` | 关闭当前 buffer |
| `Q` | 关闭窗口 |
| `M-C-q` | 关闭所有 mastodon buffer |
| `z` | 把当前 buffer 藏起来（bury） |

| `v` | 投票 |

## 五、撰写嘟文（`mastodon-toot-mode-map`）

进入撰写模式（浏览时按 `t`，或回复 `r`、引用 `"`）后生效。

| 按键 | 功能 |
|------|------|
| `C-c C-c` | 发送 |
| `C-c C-k` | 取消 |
| `C-c C-w` | 设置内容警告（CW） |
| `C-c C-n` | 切换 NSFW |
| `C-c C-v` | 修改可见范围 |
| `C-c C-a` | 添加附件（图片 / 媒体） |
| `C-c !` | 清除所有附件 |
| `C-c C-p` | 创建投票 |
| `C-c C-o` | 清除投票 |
| `C-c C-e` | 插入 emoji |
| `C-c C-l` | 设置嘟文语言 |
| `C-c C-u` | 设置引用策略 |
| `C-c C-s` | 定时发送 |

---

## 备注

- 浏览模式下的 `q` 是真正关闭 buffer，`z` 仅是 bury（可稍后用 `C-x b` 找回）。
- 部分功能（如翻译 `a`）依赖实例是否支持。
- 数据来源：`git-package/mastodon/lisp/mastodon.el`（`mastodon-mode-map`）与 `mastodon-toot.el`（`mastodon-toot-mode-map`）。
